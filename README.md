# SingIt releases

Signed builds of the SingIt Chrome extension (id `chnemnegpcbkemaaekhkchgigbgdcaik`).

Installed browsers update automatically from
`https://github.com/guypeled76/singit-releases/releases/latest/download/update.xml`.
Each release holds the signed `.crx`, a `.zip` of the same files, and `update.xml`.

To install, apply the Chrome policy for your OS from the SingIt source repo (`extension/policy/`), then restart Chrome.
