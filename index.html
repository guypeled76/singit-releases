Install SingIt

A Chrome extension that collects chords and lyrics from Tab4U, Ultimate Guitar and Shironet into your own song library.

Install

Pick your computer. Chrome on Mac, Windows and Linux installs SingIt through a small settings file and then keeps it updated automatically.

Mac updates automatically

  1. Download the SingIt profile and double-click it in your Downloads folder.
  2. Open System Settings → General → Device Management (called Profiles on older macOS).
  3. Select SingIt Chrome extension, click Install, and enter your Mac password.
  4. Quit Chrome completely (⌘Q) and open it again.

Windows updates automatically

  1. Download the SingIt registry file.
  2. Double-click it and accept the prompts. This needs an administrator account.
  3. Close all Chrome windows and open Chrome again.

Linux updates automatically

Run in a terminal, then restart Chrome:

sudo mkdir -p /etc/opt/chrome/policies/managed
sudo curl -L -o /etc/opt/chrome/policies/managed/singit-chrome.json \
  https://guypeled76.github.io/singit-releases/policy/singit-chrome-linux.json

Chromebook update by hand

Personal Chromebooks can't use the automatic installer, so SingIt is added from a folder. This uses only a switch on Chrome's extensions page; it doesn't change any system settings.

  1. Download the latest SingIt zip.
  2. In the Files app, open the zip, select everything inside, and copy it into a new folder, for example My files/SingIt. Keep this folder: Chrome runs SingIt from it.
  3. Open chrome://extensions (type it in the address bar) and turn on Developer mode in the top right.
  4. Click Load unpacked and choose the SingIt folder.
  5. Pin SingIt: click the puzzle-piece icon next to the address bar, then the pin next to SingIt.

Updating

When this page shows a newer version than chrome://extensions does, download the new zip, replace the contents of the SingIt folder, and click the reload arrow on the SingIt card.

If Load unpacked is greyed out, the Chromebook account is supervised (Family Link) or managed by a school or company, and extensions can't be added this way.

Check it worked

  • chrome://extensions lists SingIt. On Mac, Windows and Linux it can take a minute after Chrome starts and is marked as installed by your organization.
  • Mac, Windows, Linux: chrome://policy lists ExtensionInstallForcelist with status OK. Click Reload policies if SingIt hasn't appeared yet.

Using SingIt

  1. Click the SingIt icon in the toolbar to open your library, then sign in with Google.
  2. Open a song on Tab4U, Ultimate Guitar or Shironet. The SingIt icon shows a green +.
  3. Click the icon to import the song into your library.
SingIt is invite-only. If it says your account doesn't have access, ask the person who shared SingIt with you to add your Google account.

Uninstall

  • Mac: remove the SingIt Chrome extension profile in System Settings → General → Device Management.
  • Windows: in the Registry Editor, delete the value under HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Google\Chrome\ExtensionInstallForcelist that mentions chnemnegpcbkemaaekhkchgigbgdcaik.
  • Linux: sudo rm /etc/opt/chrome/policies/managed/singit-chrome.json
  • Chromebook: click Remove on the SingIt card in chrome://extensions.

Restart Chrome afterwards.
